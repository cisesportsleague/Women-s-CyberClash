# Women's CyberClash announcement and additional info

# Tournament info

- **Tournament VRS Tier** - VRS Tier 2 

- **VRS publication date used for seeding:** November 2026

- An official application will be submitted to HLTV.org for VRS inclusion. Please note that HLTV.org makes the final decision on which matches count towards the ranking.


# Tournament Format
Tournament contains following stages:

- Open Qualifiers Stage - (Online - Single Elimination BO1/BO3 for Quarter-Final Matches - 21st of November - 22nd of November 2026)
- Main Event Group Stage - Best 8 teams from Open Qualifiers (Online - 23 - 27th of November 2026 - 2 GSL BO3 Groups. Best 2 teams from each group advance to the play-off stage)
- Main Event Play-off Stage - Best 4 teams from Main Event Group Stage (Online - 28th of November 2026 - 29th of November - Single Elimination BO3 with 3rd place decider).


# Open Qualifiers
